## 3. 新实验链和性质范围

- `experiments/hydro_valve/run_tdsc_contract_chain.py`：运行原始 `HydroPlant`；独立 `UnprivilegedController.decide(packet,memory)` 只读取 PLC-local 可信有界误差观测、被破坏的 HMI 数据、未经信任的联邦上行报告及模型更新；攻击日程、真状态、clean shadow 和攻击者标签不进入在线方法。
- 独立执行层基于**六状态完整离散 Euler 动力学**的区间传递，为所有后屏蔽命令攻击 `|a^u|<=0.08` 和声明扰动计算保守一步后继状态包络；只有整个区间安全且输入预留扰动余量才释放动作。无合格候选、超预算、状态覆盖不成立时返回明确失败，绝不释放未验证 backup。
- 安全证明是**可信局部观测覆盖、模型正确、扰动界成立、找到可认证命令条件下的采样点安全**，不是连续时间全程前向不变性，也不是 IEEE39 全状态鲁棒 CBF/CLF 认证。参见 `docs/TDSC_R1_INTERVAL_CONTRACT_PROOF_20261125.md`。
- 物理恢复定义：攻击末时刻 `t=239` 的真实流量 `|q_j-q_j^ref|>0.012` 或转速 `|omega-1|>0.008`，之后首次满足两项恢复阈值并连续保持至少 20 点；攻击末仍已在恢复集合内不计成功事件。0.05 s 采样；真实指标只在离线日志审计使用。
- 该原型的静态回退使用假设可信的独立 PLC-local 通道和检查点；未验证该可信通道的真实部署、密码学认证或物理测量误差覆盖。

## 5. 同执行合同的因果对照

在相同系统模型、随机流、攻击、控制约束、20 点恢复判据下新增 `supervisor_only`（只用局部可信观测、固定参考控制器及相同安全监督器；不读取联邦数据），与 Full 全部 400–419 种子做配对。

| 测量 | AEFC-Full | Supervisor-only |
|---|---:|---:|
| Physical-only 真正恢复 | 20/20 | 20/20 |
| Joint 真正恢复 | 20/20 | 20/20 |
| Physical-only 恢复等待均值（步） | 16.65 | 16.50 |
| Joint 恢复等待均值（步） | 16.65 | 16.50 |
| 两方法已认证执行样本（各自） | 38,400 | 38,400 |
| 合同失败与采样违规（各自） | 0 | 0 |

匹配种子 Full–Supervisor 的恢复时间差在 Physical/Joint 均是 **+0.15 步**（配对 10,000-bootstrap 95% 区间 [0.0,0.3]）。攻击后流量 MAE 的配对差：Physical-only 为 **−5.3347×10⁻⁵**，Joint 为 **−6.9109×10⁻⁵**；后一指标支持很小的流量跟踪改善，不足以宣称联邦学习恢复速度更好。未做多重检验同时区间校正。

## 6. 投稿前必须继续关闭的 P0

1. **原生 IEEE39 无特权控制链**：隔离主原生控制器的 `cleanBelief` 和 `provenance` 在线权限，基于真正可观测的局部监督器和独立覆盖区间完成修正；冻结旧论文实验不覆盖。
2. **原生 IEEE39 完整执行合同**：实现可复核的硬约束鲁棒 QP 或离散等价保守对偶、安全集全状态估计、控制攻击、输入余量、QP 超时、独立 backup 可行性、每个采样保持区间；本次液压离散算法不替代这些。
3. **联邦学习增益证明**：在相同认证执行层下，分别比较 Full、Supervisor-only、RobustAgg、FedRL、PATBU/TGOPA 消融，出现确实可恢复且需要有效学习动作的条件，使用新的冻结未见种子与独立物理效用指标，不得选择性修改判据。
4. **真正异构共享神经 backbone**：当前实验是四维解析控制参数，不是多智能体深度 actor/critic 训练或可泛化 FedRL 验证。
5. **信任与理论边界**：可信 PLC/模型/扰动预算尚未在真实平台建立，不声称硬件级、密码学级或连续时间形式化安全。

**本阶段客观结论：** 建立了一条原生两阀门 SIL 上可审计的“无真值在线决策—条件性离散安全执行—真正集合外物理恢复”链条，且如实记录不可行失败。对照显示恢复主要来自可信回退，尚不能把恢复效果归因于 AEFC 联邦知识/策略适配。
