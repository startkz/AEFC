# G/H 补充核验：同算子影子参照、投毒后参数演化与物理扰动预算

## 实验与来源
- **已有原生 Main Experiment**：R2024b IEEE39，7×4×20=560 回合；全部保留，不修改任何配置/数值。
- **已有补充实验**：720 回合原生 E1/E2/E5，保留已有 artifact 与审核工件。
- **本次新运行**：GitHub Actions [39386495369](https://github.com/startkz/AEFC/actions/runs/39386495369)，commit \`132006a4f1fe936803e140441d49d8bb0326404c\`；reduced-order CPS，\`experiments/run_p0_shadow_contract.py\`，固定40个 seeds ×2 个攻击条件（仅知识投毒/联合破坏）×240步=**80回合、19200样本点**。攻击活动窗口 [24,72)，停止后继续观察168步。7个报告者，其中2个被投毒，在线证据接收端**不得读取**恶意真实身份、干净参照或干净目标向量。安全投影仍接受仿真物理状态（独立监督组件），因此这**不是**原生物理全链路的无特权状态估计验证。
- 干净影子信念使用与攻击分支**相同的PATBU代码和参数**，初始条件相同；两分支在相同的**实际物理轨迹**上接收干净/被攻击观测和证据。影子路径与历史报告参照并行计算，但**不反馈在线动作、Gate或部署**。
- 参数参照为另一个独立更新的**动态干净知识影子策略**，不是G3保证所要求的固定最优解或经认证的收缩目标。
- 原始JSONL、80份独立摘要、CSV与manifest均由一次GitHub工作流发布。没有更改Main或重命名原有560/720结果；此试验**非IEEE39原生/认证CBF-QP**。

**合计**：3368/19200（17.54%）的实际高斯噪声幅值超过确定性配置预算，最大观察值为0.013449。每回合的采样违规都为0不意味着满足G5前提。每40个零事件回合的双侧Wilson95%上界约为0.0876，仅是回合安全事件比例的统计精度，不能与任何连续时间全状态安全概率或形式认证混同。

### 分析与解释
**G1**：原始“clean belief reference”采用的参考更新过程不同于PATBU；新实验建立同算子对照，表明两类误差数值显著不同。这里**仅**得到配对轨迹上的经验误差，没有估计并认证T算子收缩系数λ_b、有效输入最坏界或理论B_b(t)。在线“时戳”依旧是报告字段，尚未实现认证接收时序与防回放服务；不能据此声称完整来源可信。

**G3**：显式逐步记录\`theta_online\`、\`theta_clean_shadow\`、\`adapt_accepted\`、\`step_norm\`、\`step_bound\`，可逐步验证单次已接受参数变动不超过其实现步长上界。尽管停止攻击后每种子都发生168次接受更新，在\`EPS=0.01\`、连续20轮判据下，仅知识投毒3/40，联合攻击1/40达到经验容差，**但这4个种子在投毒停止时就已满足阈值（time-to-ε=0），不是从阈值外收敛后的成功纠正；观察到的从阈值外到阈值内的持续纠正为两组均0/40**。动态干净目标在随时间变化，不能用这些数据证明定理中的收缩因子、固定不动点、或有限ε修正；相反，这揭示了G3实证闭环仍不充分。

**G5**：\`RobustBoxShield\`给出采样箱约束修正而非正式的在线鲁棒CBF-QP；实际\`ReducedOrderCPS.step()\`加入不截断高斯噪声。由于干扰预算在17.54%的样本点上失效，经验零采样违规不能支持对全部允许不确定性上界的断言；更不包含连续保持区间/认证状态集合/实时截止时间证书。无权将这一证据改写成“证明G5”。
