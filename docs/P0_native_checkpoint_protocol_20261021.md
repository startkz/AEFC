# P0 IEEE39 恢复机制改进——检查点隔离/回滚的独立原生验证协议

冻结日期：2026-10-21。原 Main 560-run、E1/E2/E5 原生720-run、原 E5 新120-run、原 G3 参数恢复120-run及降阶对照全保留，不修改、覆盖、并入本次正式统计分母。

## 问题出发点及改进边界

此前原生 G3 验证表明，实际四维 \`theta\` 在知识投毒/联合破坏下相对离线动态干净影子的末端残留平均约 0.010048/0.010147，投毒后的176次接受更新没有一例满足 \`epsilon=0.001\` 持续20点纠正。本实验不调整epsilon、不使用离线干净影子作为在线回滚目标，也不增加人为固定最优解。

本次**新方案只针对当前原生控制器实际部署的4维参数**提供一个性质可审计的恢复过程，并不宣称已经验证完整神经联邦共享骨干或G3固定最优解的假设。其基准是投运窗口缓存的**本地隔离检查点**，不是事后从攻击者提供的标签或无污染真值中算出的最优目标。

## 三条相同在线接口的处理臂

- \`AEFC-Unprivileged\`：在线PATBU在证据融合时不读取合成拜占庭身份位；在线Gate不读取由污染身份生成的 \`cleanBelief\`。保留原截尾聚合、风险授权、梯度裁剪、TGOPA参数更新和原生执行。
- \`AEFC-Quarantine\`：在上一条控制链上增加固定的客户端报告残差探测（客户端证据相对于坐标中位数的最大L2距离 >0.35），一旦触发就隔离/冻结后续不可信参数部署；连续3个正常报告后继续保持冻结，不作参数回滚。
- \`AEFC-Checkpoint\`：与上条保持同一探测及隔离；3个连续正常报告后，对已隔离参数递推执行 \`theta_{t+1}=theta_cp+0.5(theta_t-theta_cp)\`，直至检查点距离≤0.001，随后原子恢复到隔离检查点并保持。实验将独立检查每次处于回滚状态的离散步是否满足 \`||theta_{t+1}-theta_cp||≤0.5||theta_t-theta_cp||\`，不满足则强制审计失败。

**检测阈值的来源**：过去原生探索种子0–19的客户端证据分散度检查中，正常采样最大值0.320以内、投毒窗口最小值约0.384；只为预设本次的阈值0.35。正式测试采用**完全不重合的种子20–39**；测试后不调整阈值。没有就跨场景、低慢或自适应恶意报告防御作无条件保证。

**检查点假设**：在原生控制器投运第10采样时刻截取并隔离一次本地已部署状态；预设知识投毒从第15采样开始。当前仅在模拟器中确保快照的内部访问与后续可用，**没有实现密码学签名、硬件抗篡改、安全启动或独立证明健康投运**。若投运窗口已经污染或检查点遭篡改，收缩数学式不保证回滚到可信策略。

## 正式实验矩阵与不可绕过的验收规则

- 原生 MathWorks R2024b \`IEEE39BusSystem\` 与已验证 \`paired-generator-physical-speed-v2\` 接口，保持原受控对象、原报告投毒与屏障后物理攻击模型。测试场景：clean、knowledge-only、joint 三组；三种处理臂；各20个held-out种子，预计**180回合、39600采样点**。
- 步0..219，攻击步15..43，176个采样点在攻击结束后。记录完整\`theta\`、动态离线同算子影子、预攻击检查点、在线源报告散度、隔离告警、恢复阶段、每步执行的回滚量、实际物理状态代理、执行控制量、已接受部署标志。
- 预冻结经验阈值：\`epsilon=0.001\`（检查点恢复）、连续20采样点保持；不把攻击停止时已处在容差内的回合作为“事后纠正”。另外报告从首次检测到回滚完成的时延，并区分攻击期间隔离和攻击后回滚。
- 正常条件重点核对**错误隔离率**；攻击条件核对报警覆盖、报警时延、进入回滚/正常状态前报告连续判据、检查点误差与动态离线干净影子残差。全部种子无论成败均入表，不因失败筛除。
- 与原版原生 G3 **不同之处**在于去掉了在线身份和干净参考特权，并引入可信本地锚定；因此不能声称本次前73点与旧Main完全数值复现。旧Main仍为历史权威来源。
- 物理结果：记录每回合\`mean ||z_t||_1\`和\`mean ||u_t^{exec}||_2\`两项**独立响应/代价代理**以及真实观测的状态安全/恢复阈值越界；在没有初始脱离恢复集的情况下，不得使用“失稳后恢复时间优势”或“正式安全—效用Pareto最优”措辞。
- 所有\`theta\`为原生现有的4维部署控制系数，**不是**深度网络骨干。回滚至投运前检查点不等于回到动态干净影子、经认证固定最优解或端到端功率网络状态恢复；G5连续时间鲁棒CBF-QP执行合同仍未证明。

## 预期解释原则

如果检查点误差下降但干净影子误差升高，必须同时报告为“检查点回滚成功但存在适应性/漂移代价”。如果报警漏检、正常误报、约束失败或原生安全事件出现，必须保留并说明。不能通过修改\`epsilon\`、删除失败种子或引入知识投毒时间真值触发器追求表面成功。

## 审计完成：结果与预设协议核对

真实原生 run 39555085441 的 clean/knowledge/joint 三个作业全部成功。独立 CI run 39559082604 完成180条完整轨迹、39600样本点、归档SHA256、在线异常散度、检查点参数距离及收缩步骤复核，并已把原始轨迹及逐种子报告持久化。实际结果：正常20个独立种子中0误报；知识投毒、联合攻击两组的检测方案均20/20在首个攻击步报警。Checkpoint每组20/20最终维持静态投运检查点距离≤0.001，其中19/20是投毒后从容差外真正进入容差内；1/20在攻击停止时已在容差内。每组13个种子仅出现1个回滚阶段样本、7个进入时即直接完成；因此**未从数据获得多轮收缩率的普遍实证**。与无回滚对照相比，知识投毒/联合攻击的末端动态干净影子距离及独立物理响应L1明显增大，显示回滚抑制了部署学习与物理响应能力，不应将其表述为G3到当前干净目标的恢复。所有场景下均未观察到采样安全违规，但不提供G5连续时间认证。
