- 继续采用7个收到的恢复报告。逐维中位数残差≤0.35可构成报告一致集；再学习计算需要≥5份。仅当七份报告全部落在一致范围且在线门和代理门均接受时，记录1次重入可信样本；连续3次后允许从隔离检查点恢复受限部署。**一致性不等于真实来源认证**；如果七份信息串谋一致，重入条件可以受骗。检查点是攻击前第10步采集的**假定隔离完好**的投运快照，尚未完成抗篡改证书。
- 代理继续从收到的多数一致报告及实际收到的物理观测更新。对新机制采用固定可信锚点 `theta_a=checkpointTheta` 和 `lambda=0.08` 的近端正则化：仅在接收验证认可的学习步，对代理和对应离线干净参照（各用自身知识报告）执行
`theta_(t+1) = (1-lambda)*(theta_t+delta_t) + lambda*theta_a`。
- 回退后实际部署控制器只以在线代理为目标，以 `clip_norm(theta_proxy-theta_deployed, 0.01)` 作单次有界追赶，两个在线风险门仍必须接受；不能从离线参照、真实攻击标志或注入者真值导入目标。
- 离线 `clean_shadow_theta` 对**新方法**采用与其在线代理**相同的固定锚点正则化参数算子**，但使用离线不受攻击的报告和观测，仍仅供诊断。老三方法保留各自原更新算子与参照；**不可将“新正则化目标附近”无条件等价解释为原旧无正则化目标附近**。特别核对物理L1、执行L2是否因正则化而牺牲效用。

## 条件收缩表达式及其边界
设代理参数与新机制同算子离线反事实距离 `d_t=||theta_proxy,t-theta_shadow,t||_2`。当受检验的两条更新均被接受且两者共享相同 `theta_a` 和 `lambda` 时，有
`d_(t+1) ≤ 0.92 d_t + 0.92||delta_proxy,t-delta_shadow,t||_2`。
如果信念误差和接收证据失真使增量差≤`b_t`，则 `d_(t+n) ≤ 0.92^n d_t + 0.92 Σ_(k=0)^(n-1) 0.92^(n-1-k)b_(t+k)`。只有进一步认证增量偏差足够小、代理/影子接受条件可持续，以及真实部署能受限追赶代理，才能推出部署误差 `e_t≤0.001`；此式不是已证实的全局G3保证，也不自动涵盖动作执行CBF。
在所示固定步定义中 `0.92` 是两个相同自适应步结束后应用仿射近端映射的系数，不是由任何离线影子反馈给在线策略的系数。若接受门不同步，则该收缩式不能无条件使用，必须在轨迹中标记不满足前提的窗口。
