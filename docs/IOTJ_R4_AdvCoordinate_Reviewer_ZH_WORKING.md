# IoT-J R4 — 审稿回复工作稿（按证据逐步完善）

**状态：非终版。** 优势估计误差已完成十种子复现实验和独立审计；40 组同字节坐标选择实验以及 96 组三种子异构性因素探索实验仍在执行。正式结果产生前不预写比较优势与百分比。

感谢审稿人指出正估计优势、真实优势和全局聚合恢复性能之间的区别，以及原稿缺乏随机坐标稀疏化与原始梯度幅值坐标选择同预算对照。此前 `random` 方法随机选取的是训练转移，**不是随机坐标**，不能用它代替本条所需对照。

**条件性数学关系。** 对固定策略 π，分别定义
`A^π(s,a)=Q^π(s,a)-Q^π(s,π(s))` 与
`Â(s,a)=Q̂(s,a)-Q̂(s,π(s))`。
只有当真实 critic 误差在两个比较点均满足 `|Q̂-Q^π|≤ε_Q` 时，才由三角不等式得到 `|Â-A^π|≤2ε_Q`。零阈值 `Â>0` 不保证真实本地优势为正；即便正优势获得可信界，也不能据此保证联邦稀疏聚合的全局恢复目标单调改善。下述实测回放误差**不是**统一 `ε_Q` 上界，更不代表最优 `Q*` 的误差。

**优势估计误差实测。** 从已经完成的 1000-episode 十种子 AEFC-FRL 检查点（种子 80—89）读取原始模型与 SHA256，使用独立需求随机种子和固定策略进行相同物理工况的配对反事实回放。运行 [42958431836](https://github.com/startkz/AEFC/actions/runs/42958431836) 已完成 10/10 且通过独立审计，得到 396 个有效样本。各训练种子平均的经验优势绝对误差为 **0.05828**（种子级 95% Bootstrap 区间 [0.05102, 0.06672]）；错误正优势占全部样本的比例 **9.78%**（[6.30%, 13.50%]）；估计与配对有限时域优势符号不一致比例 **26.66%**（[19.72%, 33.59%]）；`|Â|≤0.01` 的近零样本比例 **46.89%**（[42.49%, 52.50%]）。这些均是采样工况上的经验诊断结果，不构成真实优势的统一严格判据。

**等通信预算坐标对照。** 新增 `coord_random`（独立 RNG 不放回均匀采样模型坐标）及 `coord_gradtopk`（累积共享阶段每步 *Adam 更新前原始梯度* 绝对值排序），均在同一正优势损失、同一 minibatch、同一 Adam 次数下得到同一个最终位移，再仅改变发送坐标集合和对应最终位移值。原 `adv` 使用最终位移幅值 Top-`k`；`ordinary` 原有普通损失 Top-`κ` 则作为独立对照。严格单元测试及 IEEE39 冒烟 [42956431621](https://github.com/startkz/AEFC/actions/runs/42956431621) 已通过位移一致、固定稀疏坐标数和实际应用层字节相等检查。正式完整训练 [42957084297](https://github.com/startkz/AEFC/actions/runs/42957084297) 尚待 40/40 全预算与逐轮字节独立审计，不预填效果结论。

**适配器、异构性与因素交互。** 已核对本实验可执行学习器：在维度受限工况下，客户端观测输入分别为 6 维和 3 维，本地编码器输出 32 维，共享骨干 24,864 个参数，输出适配器及 critic 保留本地。新建 2³ 因素组合，分别考虑观测维度、奇数序号客户端执行器 0.6 限幅，以及合法需求于特定步发生 6% 变化。比较 AEFC、仅冻结本地适配器训练、仅关闭原型对齐以及密集 FedRL。前两种消融不应误称“删除了适配器结构”或“所有原型机制均被取消”；FedRL 上传稠密参数，其真实字节不同。32 维同维表示和原型距离变化不能直接证明物理语义兼容。八因素组合结构冒烟 [42958645635](https://github.com/startkz/AEFC/actions/runs/42958645635) 已通过；96 组三种子完整预算探索实验 [42959386414](https://github.com/startkz/AEFC/actions/runs/42959386414) 尚未完成审计，不能表述为十种子确认结论。

**冻结聚合更新的物理检验。** 已实现对同一冻结本地适配器应用聚合更新前后的配对工况评价，并通过短预算功能测试 [42959621587](https://github.com/startkz/AEFC/actions/runs/42959621587)。该测试尚无可用于投稿的 1000-episode 正式证据，不能将短跑结果解释成联邦目标改进结论。

上述结果全部严格限定为 IEEE39 **准静态 AC** 场景，不能替代原始 Simulink–Python 六方法复现实验，更不能代表暂态频率安全认证。待坐标与异构性实验通过完整审计并核实对应最新论文 LaTeX 源文件后，再据实修改方法节、实验节、附录及中英文定稿。当前仓库 `SystemModel.tex` 包含另一 AEFC/PATBU 有界权限方法内容，不能未经比对直接作为本条 IoT-J AEFC-FRL 原始方法源码修改。
