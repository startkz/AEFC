## 1. 优势估计的条件性结论与经验误差

## 2. 等字节坐标选择

在每个客户端共享步骤内，adv、coord_random 和 coord_gradtopk 使用相同正优势目标、样本批次、归一化权重和两步 Adam 更新。先计算完整最终 Adam 位移，再选择发送坐标。adv 选择最终位移绝对值最大的坐标；coord_random 均匀无放回随机选择 k 个坐标；coord_gradtopk 根据 Adam 更新前原始梯度绝对值累积和选择坐标，但上传值仍取自最终 Adam 位移。ordinary 使用普通损失，是独立优化目标对照，不是纯坐标选择消融。

Run 42957084297 已完成40/40单元（种子80–89 × 四种方法），包含40,000条训练 episode、8,000轮联邦训练和400个 held-out tests。独立物理审计和 detached manifest SHA256 清单均通过。每个运行单元实际应用层上传40,230,000字节；每个种子内四种方法逐轮字节完全一致。

## 3. 观测、执行器与需求异构性

Run 42959386414 已完成96/96单元，即八种因素组合 × 四种配置 × 三个种子（80–82）。每个单元均执行1000 episodes、200轮联邦训练和10个 held-out tests，共96,000条训练 episode、19,200轮和960个测试。独立 manifest 审计核验了全部96组 JSON/PT/manifest 及 detached manifest SHA256。该实验仍是**三种子探索性因素实验**，不是十种子确认实验。

观测因素将客户端输入维度从 [6,6,6,6,6] 改为 [6,3,6,3,6]，并核验对应编码器参数量。执行器因素将奇数序号客户端命令上限设为0.6；训练轨迹共核验288万个受限客户端步进，其中694,093次达到0.0108的服务负荷增量上限，未发现超限。需求因素在 AC 第12步将奇数序号客户端的实际物理需求提高6%；该变化在48,000条训练 episode 和480条 held-out 轨迹中均得到核验。

部分 held-out 结果显示观测异构性可能影响不同配置。在 dim_shift 下，adv 的终端负荷为90.72%、五步安全恢复比例为0.167；dense FedRL 分别为90.57%和0.133。adapter_frozen 分别为99.28%和1.000，proto_alignment_off 分别为94.36%和0.900。在 dim 单因素下，adv 为93.08%和0.400，dense 为92.74%和0.333。每个单元仅有三个独立种子，这些数值及其 Bootstrap 区间仅用于探索性描述，不能建立总体性能排序。adapter_frozen 保留适配器结构，仅冻结本地适配器训练；proto_alignment_off 仅关闭本地对齐，不代表删除全部服务器原型元数据。dense FedRL 的实际通信量更高（每单元199,358,000字节），稀疏配置为40,230,000字节。

96,000条训练 episode 中有31,613条右删失。失败样本分数31仅为受限比较编码，不是实际物理恢复时间。
