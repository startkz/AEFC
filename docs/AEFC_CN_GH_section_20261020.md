## G．理论保证的机制级补充核验

为区分同算子参照误差、历史不同算子参考量与部署参数真实序列，本研究新增独立的降阶 CPS 机制级试验，采用40个固定随机种子、知识投毒与联合破坏两种条件、每回合240步，共80回合。攻击活动窗口为[24,72)，停止后再观测168步。7个报告者中2个报告遭篡改，在线学习权限链不读取真实恶意身份或干净参照；同算子干净影子只用于离线评价。该结果不能等同于原生IEEE39验证，也不能替代认证状态监督。

**G1：同算子信念诊断。** 干净影子与受攻击分支执行相同PATBU算子和参数，但接受同一物理轨迹上的配对干净/受攻击证据。每回合最大同算子误差跨40种子的均值，在知识投毒下为0.007486（20,000次种子bootstrap逐比较95%区间[0.00711,0.00786]），在联合破坏下为0.413283（区间[0.41174,0.41482]）。原旧参照（不同更新算子）对应均值分别为0.093304和0.482149。旧实验诊断不能重命名为理论G1误差。此处也没有认证全域收缩系数λ、有效输入上界或最坏情况B_b(t)。

**G3：投毒后完整参数序列。** 全部种子都记录部署与动态干净影子参数向量、部署接受、逐步修改范数及其实现步长上界。攻击结束后每个种子均有168次接受更新。知识投毒下动态干净参数距离均值从0.022095变为0.022098；联合破坏下从0.027866变为0.025158。若要求投毒后达到参数距离≤0.01并连续保持20步，满足数分别为3/40和1/40，但这4个种子在停止攻击时已经位于容差内；以初始在容差外、之后新进入且连续保持20步作为真正的事后纠正判据，两组均为0/40。动态干净影子不是经认证固定不动点，接受更新数也不能推出全域收缩或未观测轮次的进展条件。因此不支持声称G3的普遍有限ε修正得到了实验验证。

**G5：物理扰动覆盖诊断。** 降阶执行投影报告不可行的采样数为0，80回合均没有采样状态违规；但模型实际加入不截断高斯扰动，3368/19200=17.54%的采样点超过配置的状态扰动硬预算0.006，最大观察扰动约0.013449。该采样比率不是独立二项重复。硬扰动覆盖前提并非总成立，不能把零采样违规或箱投影可行性推广为鲁棒CBF-QP及连续保持区间的定理实证。

## H．当前证据边界与后续验证协议

H并非“实验结果”，不应写成已执行的第六组主实验。保留为简短的 P0 限制与预冻结协议：原生 IEEE39 控制器的无特权在线信念／授权、真正同算子影子、独立固定干净目标、投毒后接受间隔和残差、认证全状态及扰动覆盖、真实鲁棒CBF-QP可行性、同域备用方案与全采样保持区间、最坏/分位实时截止时间等均待运行验证。前期参数E5的非激活扫描不能推导控制敏感性，后续边界单元在另一单独 GitHub Actions run 中执行。外部自适应恶意报告应限定为已授权威胁模型内的输入，接口级直接强制危险提议必须独立标明，不得等同于完整知识投毒链路。

对未来正式实验：先探索后冻结预算/样本/初始故障；方法间使用可核验配对外源随机流；保留所有未激活、不可行及错误单元；以种子而非回合内采样点作为统计重复；NE危险授权零暴露不得改成零FAR。这些未验证项目不得从理论小节里删除或在摘要中写成实验成功结论。

## 2026-10-21 后续补证结果

新完成的受控降阶pilot由固定目标与人工收缩率0.90构造，40 seeds ×2设置，总计80回合。污染后影子参数误差首轮均值bounded为0.306672、未过滤3.066720，末端分别7.00e-9与7.00e-8；两组均40/40进入并保持20步的ε=0.01容差。由于收缩率被设计预置，而非从真实AEFC学习器测得，不能将这80回合用于声称原生IEEE39 G3已被验证。箱投影及有界均匀扰动是离散时刻可行性试验，不是鲁棒CBF-QP形式执行证书。

原生E5新增独立的四通道归一化观测偏差L1和执行修正L2两项描述性成本。rho_max=0.09 的20-seed平均指标为0.020401/0.010595，rho_max=0.12为0.019708/0.018094，显示减少动作幅度可能增加响应偏差。但被测系统未先离开恢复集，故仍不支持使用“安全—恢复效用权衡”表述；应称为“局部响应—控制成本变化”。全部详细数据见 docs/P0_recovery_contract_utility_20261021.md。无特权原生IEEE39链路、真实投毒后收缩以及G5连续时间鲁棒执行仍未验证。


## 2026-10-21 原生部署参数的投毒后恢复（审计完成）

最终原生IEEE39审计通过：120回合、26,400采样点，前73点与Main的360个共同字段比较最大误差4.996×10^−16。算法实际更新四维\`theta\`，另记录离线同算子动态干净影子\`theta_shadow\`，两组场景均观察176个投毒后样本点；所有三种方法（FedRL、no-TGOPA、AEFC-Full）与20种子均在攻击停止后超出经验阈值\`epsilon=0.001\`，之后**真正纠正均为0/20**。AEFC-Full 在知识投毒/联合破坏下，末端平均距离分别仅约0.010048/0.010147，低于no-TGOPA(0.050804/0.050482)和FedRL(0.130927/0.130417)，但其40个场景—种子回合均出现局部误差回升，接受176次更新也不能证明统一收缩。论文应明确写为「降低部署偏差，但尚未实证达到有限容差纠正」，不得再称「完成真实投毒后收缩恢复」。

离线影子属于同一被攻击物理轨迹上的干净合成报告参照，**不是独立干净物理对象，也不是理论G3所要求的固定认证目标**；原生控制器仍调用合成的恶意来源标记，未关闭无特权在线入口P0。原始结果、判据、主要反例和原生溯源见[完整审校说明](P0_native_theta_postpoison_results_20261021.md)。完整中文Word对应对话附件\`AEFC_中文论文_原生G3收缩恢复实验审定版_20261021.docx\`。

## 2026-10-21 新增独立原生检查点回滚验证（审计完成）

新增完全独立的 R2024b IEEE39 held-out 种子20—39：正常、知识投毒、联合破坏 × 原生Unprivileged、Quarantine、Checkpoint，各20种子，**180次原生回合、39600个采样点**；三种场景均成功且逐轨迹及原始哈希独立审计通过。原主实验、先前 G3 等所有实验不变。投运第10步本地存储检查点，第15—43步攻击；检测端仅用接收证据分散度（阈值0.35，旧种子预选）且在线决策不读取合成恶意来源位或干净影子；检查点健康与完整性仍为模拟器假设。

新结果：两类攻击下启用检测的方案均20/20在攻击第15步发出警报，正常20个种子无误报。Checkpoint在两组攻击分别19/20实现**攻击后从检查点容差外→容差内**的纠正（其余1/20原先已达标），最终全部回到历史检查点。但知识投毒下回滚后末端动态影子距离0.064342，对照无回滚为0.010483；联合条件为0.064538对0.010420。回滚降低执行控制量同时增加归一化物理响应偏差（联合0.034712对0.019767）。回滚阶段仅观察0或1个标记采样点，不能宣称实测出长时间收缩常数。它是**可执行的静态检查点降级生存**而不是到当前干净策略、完整联邦神经网络或G3固定最优目标的真正收缩恢复；也不构成G5连续时间鲁棒执行认证。完整数据、效应区间及每种子分母见 [独立结果报告](P0_native_checkpoint_results_20261021.md)，中文全文 Word 对应本轮最终修订文件。
