## G．理论保证的机制级补充核验

为区分同算子参照误差、历史不同算子参考量与部署参数真实序列，本研究新增独立的降阶 CPS 机制级试验，采用40个固定随机种子、知识投毒与联合破坏两种条件、每回合240步，共80回合。攻击活动窗口为[24,72)，停止后再观测168步。7个报告者中2个报告遭篡改，在线学习权限链不读取真实恶意身份或干净参照；同算子干净影子只用于离线评价。该结果不能等同于原生IEEE39验证，也不能替代认证状态监督。

**G1：同算子信念诊断。** 干净影子与受攻击分支执行相同PATBU算子和参数，但接受同一物理轨迹上的配对干净/受攻击证据。每回合最大同算子误差跨40种子的均值，在知识投毒下为0.007486（20,000次种子bootstrap逐比较95%区间[0.00711,0.00786]），在联合破坏下为0.413283（区间[0.41174,0.41482]）。原旧参照（不同更新算子）对应均值分别为0.093304和0.482149。旧实验诊断不能重命名为理论G1误差。此处也没有认证全域收缩系数λ、有效输入上界或最坏情况B_b(t)。

**G3：投毒后完整参数序列。** 全部种子都记录部署与动态干净影子参数向量、部署接受、逐步修改范数及其实现步长上界。攻击结束后每个种子均有168次接受更新。知识投毒下动态干净参数距离均值从0.022095变为0.022098；联合破坏下从0.027866变为0.025158。若要求投毒后达到参数距离≤0.01并连续保持20步，成功数分别只有3/40和1/40。动态干净影子不是经认证固定不动点，接受更新数也不能推出全域收缩或未观测轮次的进展条件。因此不支持声称G3的普遍有限ε修正得到了实验验证。

**G5：物理扰动覆盖诊断。** 降阶执行投影报告不可行的采样数为0，80回合均没有采样状态违规；但模型实际加入不截断高斯扰动，3368/19200=17.54%的采样点超过配置的状态扰动硬预算0.006，最大观察扰动约0.013449。该采样比率不是独立二项重复。硬扰动覆盖前提并非总成立，不能把零采样违规或箱投影可行性推广为鲁棒CBF-QP及连续保持区间的定理实证。

## H．当前证据边界与后续验证协议

H并非“实验结果”，不应写成已执行的第六组主实验。保留为简短的 P0 限制与预冻结协议：原生 IEEE39 控制器的无特权在线信念／授权、真正同算子影子、独立固定干净目标、投毒后接受间隔和残差、认证全状态及扰动覆盖、真实鲁棒CBF-QP可行性、同域备用方案与全采样保持区间、最坏/分位实时截止时间等均待运行验证。前期参数E5的非激活扫描不能推导控制敏感性，后续边界单元在另一单独 GitHub Actions run 中执行。外部自适应恶意报告应限定为已授权威胁模型内的输入，接口级直接强制危险提议必须独立标明，不得等同于完整知识投毒链路。

对未来正式实验：先探索后冻结预算/样本/初始故障；方法间使用可核验配对外源随机流；保留所有未激活、不可行及错误单元；以种子而非回合内采样点作为统计重复；NE危险授权零暴露不得改成零FAR。这些未验证项目不得从理论小节里删除或在摘要中写成实验成功结论。
