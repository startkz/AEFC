# IoT-J R3 — 审稿意见：自适应信誉权重操纵

我们承认固定联合伪造和随机/缩放/翻转更新不足以证明抵抗以最大化权重为目标的自适应攻击。本轮在不修改服务器裁剪、验收和评分公式的条件下，联合搜索稀疏上传索引及数值、上报恢复效用和原型。攻击者仅使用自身当前上传、历史公开模型变化与原型、自身上一轮公开权重，不访问当轮诚实客户端私有数据与留出测试结果。

IEEE39 完整审计矩阵为 N=10、M=2、5 个独立训练种子（90—94），每种子训练 1000 回合、独立评估 10 回合。比较无攻击、固定联合伪造、仅最大化权重及兼顾方向性破坏的自适应攻击；强度分别为 0.25、0.5、1、2，并在强度 1 下增加仅元数据、仅更新、仅原型的消融。按种子报告配对的恢复负荷损失、安全驻留变化、恶意客户端验收比例、被接受的合计权重和逐轮轨迹。

未限权时，自适应条件中平均恢复负荷损失最大的是 adaptive_weight_050，相对无攻击同协议条件的差值为 2.82 个百分点，攻击期恶意客户端平均合计权重为 0.998；单客户端 0.20 限权时，分别为 adaptive_meta_100、0.43 个百分点、0.400。以上仅是指定准静态 AC 平台的实测结果，不构成最坏情况界、动态物理安全证明或 Byzantine 保证。当上报效用和更新范数被服务器上限截断时，标称强度增大不必然导致有效攻击增强。
