## 2. 真实模型可观测性的结构审计

对官方 IEEE39 原生模型扫描 9,102 个 Simulink 块并枚举输出接口，发现转速候选 20 路，覆盖 10 台发电机。但以当前显式信号名称和连接规则未发现验证过的母线电压、转子角和支路电流/负载通道：

<https://github.com/startkz/AEFC/actions/runs/45544601546>

“未在名称筛选中发现”并**不**意味着内部不存在物理变量。上一阶段 `xout` 的 201 个保存条目、976 个数值分量已严格分解为 AVR/励磁器 150 + Governor/原动机 30 + Grid 求解器内部数据 796；976 不能被解释为 976 个独立物理状态，更无法自动当作合法在线传感器。当前仍缺乏可识别的全部 39 母线电压、支路限值、机组角和安全控制状态的受信测量/集合型观测映射。

新建的 `aefc_ieee39_simscape_algebraic_inventory.m` 使用 MathWorks 官方 `SimscapeLogType=all` 及 `simscape.logging.getSimulationLog`（R2024a 起可用）审计 Simscape 原始物理变量日志；这只是**离线候选识别**，不会把求解器真值回灌给在线控制器。即使能成功提取，也须先验证电气量的来源、计量单位、采样时间与误差界。

## 4. 证明机制已实现：精确区间 index-1 DAE 的 Krawczyk + Picard

新增 `analysis/dae_interval_certificate.py`，对

```
xdot = f(x,z,u,w), 0=g(x,z,u,w), x in X0, z in Z
```

使用**精确有理数区间**计算 Krawczyk 算子。如果 `K(X_tube,U,W,Z)` 严格包含于 `interior(Z)`，且全参数范围的代数根算子一致收缩，则对所有允许的 (x,u,w) 可证明根存在唯一。进一步使用充分条件

```
X0 + [0,h] * F(X_tube, Z, U, W) subset interior(X_tube)
X_tube subset SafeX; Z subset SafeZ; U subset SafeU
```

证明整个保持区间的状态包含，并以

```
X(t+h) subset X0 + h*F(X_tube,Z,U,W)
```

给出一步包含。其**严格性以真实方程的 interval extension、初始集合、index-1 条件和所有扰动包络已经被验证为前提**。测试采用明确定义的合成 DAE，包含 500 次真实解析解轨迹采样以及代数解不存在、状态管太小和未验证模型条件的拒绝用例：

<https://github.com/startkz/AEFC/actions/runs/45544820665>

此证明程序尚未与真实官方 Simscape IEEE39 的完整结构方程、区间 Jacobian、代数唯一性区域和真实不确定性参数对接，故仍不得宣称“真实 IEEE39 可达集已证明”。

## 7. 后续技术决策

首先从原生 Simscape 电气网获得可明确标定的 39 母线电压、支路电流/潮流和机组角测量映射，同时区分其在原生仿真器中作为离线真值或在线合法物理传感器的使用边界。必须以实际物理电路参数和拓扑建立可验证的 index-1 DAE 及有界误差区间；仅 4×4 有限差分 Pref/转速矩阵和数值线性化不足以推导该模型。然后对备用调速器建立闭环不变性和求解失效安全动作证明，在实际电网中产生与安全假设一致、攻击结束后真实超出恢复集合的压力场景，最后冻结独立种子比较六方法。

这条路径必须优先于增加对照数量或调整阈值；当前不能把“完成 48 回合仿真”当作“完成真实物理恢复实验”。

**本分支仍应保持 Draft PR，禁止按完成全 IEEE39 P0 审批。**

## 8. 真实全网络安全状态逐谓词覆盖审计与最终验收

基于未更改的原始官方模型块图、xout 原始状态注册表、因果探测的四路 Pref/转速映射，建立 **59 项明确的安全状态—物理量测需求**：10 台机组转速、10 台机组转子角以及 39 母线电压幅值。机组速度可在离线物理模型中观测 10 路，但当前真正由无特权控制器接收的只有 4 路，且这 4 路的独立可信传感器认证与测量误差确定性界仍未证明。转子角和 39 母线电压尚无经过验证的在线观测映射。支路热限、功率潮流与内部控制器安全约束另外列为未核定量数目的全网络要求。**不存在 59/59 的完整在线状态可观测性证明。**

真实独立工作流 [59 项逐谓词覆盖审计](https://github.com/startkz/AEFC/actions/runs/45545636858) 已通过。这表示矩阵来源和缺失项可靠，而不是物理系统已认证。

将原始已复核的 **48 个真实 MATLAB 回合**、59 项安全状态矩阵和原生输出一步包络留出反例全部投入 [最终论文安全主张证据闸门](https://github.com/startkz/AEFC/actions/runs/45545863520)，运行**成功**，实质结果为 **`status=BLOCKED`**、`full_native_ieee39_execution_safety_certified=false`、`reliable_post_attack_recovery_certified=false`、`six_method_recovery_superiority_established=false`。在全电网在线测量、非线性 DAE 包含、连续时间可达集、备份稳健可行域及真实物理恢复事件缺失的情况下，这一拒绝升级结论是必要且正确的。
