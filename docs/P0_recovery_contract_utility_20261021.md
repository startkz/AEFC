# AEFC P0 新补证：固定目标收缩、执行包络和 E5 独立成本（2026-10-21）

## 数据来源及不可混淆的证据层级
- authoritative 560-run Main Experiment 不变；720-run supplemental 与120-run 原生 E5 均不改。
- 原生 E5 数据来源：[GitHub Actions #39387453311](https://github.com/startkz/AEFC/actions/runs/39387453311)，四通道归一化的 `observation_normalized` 与 `executed_correction` 重新计算**平均 L1 观测偏差**及**平均 L2 执行修正**。这两个是原生轨迹中的独立响应/代价代理，但**不是从失效集重新恢复的时间或恢复成功率**。没有认证这些观测完全反映完整物理状态。
- 新合成降阶机制试验：[Actions #39537403594](https://github.com/startkz/AEFC/actions/runs/39537403594)，80回合（40 matched seeds × 2 种攻击滤波设置）×240步，日志与manifest归档。该试验为了隔离条件，**构造了已知固定目标、由 `alpha=0.90` 保证收缩的离散参数映射，以及受有界均匀噪声扰动的箱约束离散物理模型**。它证实试验代码可触发相关机制，**不证明已部署AEFC在IEEE39上的G3收缩或连续时间G5**。

## E5 原生物理观测响应/执行成本（均为20种子回合均值后平均）
| 单元 | 平均四通道归一化绝对偏差 L1 | 平均执行修正 L2 |
|---|---:|---:|
| q_min=0.43 | 0.019708 | 0.018094 |
| q_min=0.48 | 0.019583 | 0.017433 |
| rho_max=0.09 | 0.020401 | 0.010595 |
| rho_max=0.12 | 0.019708 | 0.018094 |
| Delta_theta=0.002 | 0.018526 | 0.011985 |
| Delta_theta=0.005 | 0.018712 | 0.017456 |

该表显示较严格风险门可能减少控制幅度但增加物理偏差（例如 rho_max 从0.12降至0.09），**可称为局部“响应—控制成本”变化，尚不能写成正式安全—恢复效用 Pareto 权衡**。此前零危险暴露、零安全事件及0.0167秒报告时标仍不构成有效恢复基准。统计单位应为种子。

## 固定目标受控补证的真实输出
| 配置 | 攻击停止后第一个参数距离均值 | 末端参数距离均值 | 连续20步达到 epsilon=0.01 | 平均每步独立状态调节成本 |
|---|---:|---:|---:|---:|
| 授权抑制0.1倍污染（bounded） | 0.306672 | 7.00e-9 | 40/40 | 0.101814 |
| 不抑制污染（unfiltered） | 3.066720 | 7.00e-8 | 40/40 | 0.357044 |

在攻击停止后，无攻击更新关系为 `theta[t+1]=0.90 theta[t]+0.10 theta_star`，故两条轨迹的差满足 `||e[t+1]||=0.90||e[t]||`（数值容差内）。这是**设计上内置的受控收缩条件**，展示“满足假设时可有限进入容差”这一可执行边界，而不是从真实FedMARL训练数据估计到的收缩结论。80回合的离散箱投影都报告可行、观测点无违约；噪声使用按构造截断的均匀分布，连续保持区间未认证。这也不是实际鲁棒 CBF-QP 原生实现。

## P0 未关闭
1. 无特权 IEEE39 在线信息链：主原生控制器部分清洁参考及实验攻击身份路径仍须完全隔离；独立可信物理状态估计与证据覆盖也未验证。
2. IEEE39 真实投毒停止后策略收缩：须记录真实共享骨干、固定认证干净目标、容差/残差、接受拒绝时间、超过120轮恢复及恢复效用；新试验的人工线性收缩不能替代。
3. 物理 G5：需要独立可靠的全状态不确定集、屏障后攻击预算、真实扰动与执行输入界、完整鲁棒 QP 约束/求解状态/延迟与采样保持区间。离散箱投影零违约不等于连续时间前向不变性。
4. E5正式权衡：要先引入失效后的恢复目标与真值观测/能量代价，预先固定utility权重，独立验证明确的安全成本和恢复速度。

## 审校决定
旧实验E5从“安全—效用权衡”改为“门限激活与响应—控制成本观察”；G3新增的固定目标对照标为“受控正例”，不移除此前80-run同算子影子试验的未验证结论；G5仍仅有离散近似可行性。未经认证的关键结论不得进入摘要/结论中的无条件主张。
