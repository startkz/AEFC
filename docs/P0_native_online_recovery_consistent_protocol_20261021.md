# P0 原生在线恢复 v2：在线代理算子一致性修复与独立探索（2026-10-21）

**性质：机制修复 + 独立探索；非既往 frozen 40–47 结果的重新命名；不具有 G3/G5 认证含义。**

## 研究动机
旧版审计 `39562986733` 在种子 40–47、72回合、34,560点的原生 IEEE39 试验中，知识与联合攻击各 0/8 达到动态干净影子纠正（`epsilon=0.001`, 连续20点），尽管 OnlineRelearn 每攻击种子平均接受 421.125 次部署更新。原始完整数据及历史代码均保留不可改动。

对控制器逐行审查发现在线代理使用 `fSafe=min(1,f)`，而离线干净影子在全部7份报告时用 `f=2`；代理门的“观测－信念”创新范数与干净影子的“信念－历史基线”创新范数也不一致。在无攻击恢复期，即使代理收到7份一致报告，两者也不遵循相同更新算子。本轮仅修复这两处可证实的实现不一致。

## 固定验证设计
- 使用独立 GitHub 分支 `experiment/native-online-recovery-consistent-20261021`，保留旧 PR#3 和全部旧结果。
- 在原生 MathWorks R2024b IEEE 39 模型，沿用原实验已验证的4维物理映射；三场景 `clean`、`knowledge`、`joint`；三方法 `AEFC-Unprivileged`、`AEFC-Checkpoint`、`AEFC-OnlineRelearn`。
- 新探索种子 **48–55**（非40–47重跑，且与将来的80–119独立确认集不相交）。每单元8个种子，每回合480点，攻击时刻15–43，攻击后从44开始，计72回合/34,560点。
- 保持检测阈值0.35、3步清洁重入、在线跟踪因子0.25、跟踪L2单步0.01等参数不变；使用报告逐维中位数半径0.35内的接收端一致集（至少5/7）决定代理更新，不输入真实恶意身份、攻击日程或离线干净影子。
- 原生 `clean_shadow_theta` 仅用于离线逐时刻审计；原始主实验、旧检查点实验和旧在线实验均不修改。
- **主判据不变**：`e_t=||deployed_theta-clean_shadow_theta||₂`, 攻击后 `e_44>0.001`，之后进入 `e≤0.001` 并保持连续20个采样点才称纠正。逐种子记录所有相邻/10步窗口比值、接受更新、失败数、物理响应L1、执行控制L2和采样安全越界；不丢弃不利样本。
- 即便主判据通过，也只能称**探索性的实际部署四参数动态影子纠正**，不代表全联邦深度网络收缩定理或连续时间鲁棒CBF-QP认证。

## 与原命题分离的事后敏感性
基于已经冻结的旧 run 39562986733 原始轨迹进行事后容差扫描（epsilon=0.001,0.002,0.003,0.005,0.01,0.015,0.02,0.03；保持5、10、20、40点）。例如旧 OnlineRelearn 在 `epsilon=0.01, hold=20` 下知识投毒6/8、联合攻击2/8，而原 `epsilon=0.001, hold=20` 均0/8。该扫描只衡量经验尺度，不更改/替代原预注册判据，绝不据此认定原试验通过。

## 理论与失败语义
即使代理更新算子与干净基线一致，也不能保证原攻击期间代理状态和参数同干净影子一致。历史污染造成的积分偏差可能在无严格收缩机制时保留，且多数一致不防御5/7协同污染。静态投运检查点也不是当前动态影子。若 v2 未进入 epsilon20，则**如实报告并继续研发可信在线状态重入、梯度动力学收缩条件和偏差上界**，不在原始数据上筛种子或人工增设Oracle反馈。
