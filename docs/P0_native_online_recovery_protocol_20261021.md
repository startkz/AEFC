# P0 原生 IEEE39 在线再学习恢复：探索阶段预注册协议（2026-10-21）

状态：**探索阶段协议与实现；任何新结果在 Actions 与独立原始轨迹审计完成前均不成立。**

## 研究假设与可证伪点

上一轮 R2024b 原生180回合（[run 39555085441](https://github.com/startkz/AEFC/actions/runs/39555085441)；[审计 39559082604](https://github.com/startkz/AEFC/actions/runs/39559082604)）证明了在检查点假定完整时的静态回退/降级生存，却没有向动态干净影子收缩：两种攻击下，Checkpoint 末端动态影子距离均约0.064，且回退后接受学习次数为零；每组仅13/20出现单个显式回滚阶段点，无法从轨迹估计多轮收缩率。

本次检验更强但仍非形式认证的命题：仅根据在线收到的七个报告与同一物理观测输入，经过不可信报告隔离后，建立一个 **不调用离线干净影子** 的在线多数一致参数代理，恢复受限部署更新。检验是否能使实际部署参数接近同时刻同算子离线干净影子，且不以更差的物理响应/安全代价掩盖误差改善。若代理有偏、报告集体伪装或Gate长期拒绝，允许并完整呈报失败。

## 冻结设置

- 平台：MathWorks R2024b IEEE39，原映射 `paired-generator-physical-speed-v2`，四维真实部署系数；不称作联邦深度神经骨干。原Main、E5、旧G3和180-run数据全部只读。
- 三种场景：`clean`、`knowledge`、`joint`；三种方法：原`Unprivileged`、旧`Checkpoint`、新`OnlineRelearn`。本轮探索种子40–47，每个单元8个不同种子，**72回合 × 480点 = 34,560样本**；探索性试验不作确认性显著性声称。
- 投毒15–43（两端包含），本轮持续记录至步479，即攻击后436点。第10步截取未认证投运检查点；检测阈值0.35；连续3个报告一致样本后进入再学习。该门限仍仅来自旧种子0–19；不在这8个种子的观察结果后修改阈值。
- 被信任的在线代理：每步从七个当前报告的**逐维中位数**计算L2残差，保留残差≤0.35的报告；要求至少5个保留，否则本步代理不得更新。代理基于保留者报告、截尾/公共支撑梯度、独立信念和原Gate条件推进；不使用攻击是否发生、真实恶意身份、`cleanBelief`、`clean_shadow_theta`、未来观测或预先计算的理论最优参数。被投毒的物理测量仍可能污染代理，必须在联合破坏组检验。
- `OnlineRelearn` 在报警后先停留隔离检查点；清洁连续3步后以 `0.25(theta_proxy-theta_deployed)` 且每步 L2≤0.01 的**在线代理跟踪更新**重新进入部署，受报告清洁、代理Gate与在线Gate共同限制。这里的0.25只定义**到估计代理**的受限跟踪，**不是**预置到离线干净目标的收缩常数。检查点和代理均假定局部运行环境不被攻击者篡改。

## 原始数据和逐种子验收（禁止改分母）

必须审查3×3×8条 JSONL，每条480个时间严格递增的原始点，配有逐种子 `summary.json`、每场景24行 `summary.csv`、`manifest.json`、`raw-traces.tar.gz`及SHA256。缺失任何原始点、种子或方法时整项审计失败；对于数值上未激活/不收缩/恢复不可行者，只在表内标为失败，不能删除。

每点记录实际 `theta_t`、离线干净影子 `theta_t^{shadow}`、在线代理 `theta_t^{proxy}`、检查点、Gate决定、被接受的更新、相位、报告一致集数量、归一化物理状态、实际执行控制量。独立 Python 审计重算所有三种距离并验证摘要。

以**同一物理轨迹、同一更新算子**的离线动态干净影子作事后诊断参照，定义 `e_t=||theta_t-theta_shadow,t||_2`。`epsilon=0.001`、连续20点；只有在攻击结束后第一个采样点 `e_44>epsilon`，以后**由外向内进入**并连续20点才叫经验纠正。另必须逐种子报告最终误差比、逐点实际比值、多重连续下降长度、**所有**10点误差比窗口（非挑选最佳窗口）、所有二阶比较的Gate拒绝和代理误差，不从单个回滚样本推断多轮收缩。

对同种子三方法分别比较攻击后部署接受数、采样安全越界、完整四通道归一化物理响应L1和执行修正L2。没有初始离开恢复集，不得声称失稳后物理恢复时间优势；没有独立全状态及连续时间CBF-QP证明，不得称作G5认证。

## 解释及继续扩样条件

本轮**探索**只判定机制实现与数值走势。即使在72回合中观测到真实动态影子误差连续下降，也只能称「在探索种子上的动态干净影子经验收敛」，**不得称为G3形式收缩认证**。下一阶段必须在种子80–119各场景等额配对、冻结代码和全部阈值后作**独立40-seed确认性验证**，并对低慢/协同恶意、错误检查点与观测扰动做失效压力测试。

未通过 `epsilon20` 的种子、无法进入Gate的种子、物理代价恶化和多轮回升都是重要的否定结果。**仅增加实验数量并不能改变冻结的静态回退缺陷。**
