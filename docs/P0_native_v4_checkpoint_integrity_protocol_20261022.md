# AEFC v4 隔离检查点完整性校验与错误锚点拒绝：预注册原生验证（2026-10-22）

**研究类别：新的独立探索实验，必须在原生作业及逐轨迹审计完成后才成立。原 v3 56–63 探索、80–119 冻结独立确认、64–71 压力测试均只读。**

## 基准和明确威胁模型
- 前一轮原生 R2024b IEEE39 的原始事实：v3 新同锚近端正则化学习算子在种子80–119 knowledge与joint均40/40 达到 `epsilon=0.001,hold=20` 的同算子动态影子经验纠正；原无正则化策略不作为本次干净参照。独立压力测试中，故意把未认证 checkpoint at t20 修改 `[+.06,-.06,+.06,-.06]`，造成原v3 8/8无法纠正，末端差约0.12。
- 本次选择**显式隔离信任模型**：在 t10 前置登记阶段，将4维 `checkpointTheta` 同时复制到受保护的 `pristineAnchor` 参考槽；攻击者可改写工作检查点槽，但**不能改写参考槽及其读接口**。每次模式5使用4个双精度比特模式完整比较；发现不一致则拒绝受损检查点，恢复受保护参考副本，再重新执行原有3步清洁在线门控。这是**完整性认证机制的理想化隔离参考模型**，并非密钥签名、HMAC、TEE或实际安全硬件实验；若可信参考槽也能被攻击，则本实验不提供保证。
- 运行期不使用 `clean_shadow_theta`、离线反事实信念、真实攻击时间/恶意身份、未来观测作为控制输入。压力脚本可以知道注入时间，只有离线审计记录这些攻击真值。
- 方法组：`AEFC-Unprivileged` (mode0)、`AEFC-Checkpoint` (mode2)、`AEFC-ContractiveReentry` (mode4)、`AEFC-AnchorAuthenticated` (mode5)。三旧方法在**独立复制的压力控制器**中不读取可信参考副本，保持其失败逻辑；新方法仅增加封存副本完整性校验/恢复，仍使用prox=0.08、每步L2≤0.01、scatter=0.35、连续3步重入、原两个Gate及原执行约束。
- 离线干净策略参照对 mode4/5 都使用**未污染的 t10 原始锚点、相同的prox算子、各自同物理输入轨迹**，只用于离线分析；因此不能混称为原无正则化策略的恢复。

## 完全预定的原生矩阵
- 平台：MathWorks R2024b 原生 IEEE39 物理模型 `paired-generator-physical-speed-v2`、真实部署4维theta。
- 探索性新种子 **120–127**，不与0–119任何旧数据混合；场景6种：① clean(no stress), ② joint (original attack15–43), ③ collusion（2/7协调伪造报告15–43）, ④ persistent_bias（控制端观测15–180被污染）, ⑤ checkpoint_tamper（t20将工作锚偏移0.12）、⑥ joint_checkpoint_tamper（联合物理/知识攻击15–43，并同时在t20篡改工作锚）。后四种隔离红队只用新实验注入接口，不改变原560-run主实验。
- 共 **6场景×4方法×8种子=192回合，每回合480点，合计92,160原始点**。所有失败、无法重入、首次退出不满足以及误报都必须记录，不得事后调整攻击、阈值、分母或目标定义。
- 主判据沿用旧制：`e_t=||theta_deployed,t-theta_clean_shadow,t||2`，仅当攻击真实结束后的首点 `e_post>0.001`，后来在`e_t≤0.001` 连续20点，才报告经验纠正。persistent_bias以t181为首次后攻击点；其余受攻击场景均以t44为起点。clean组无需纠正，验证0误报、代理及物理成本。
- **主动拒绝有效性**：检查点篡改组 mode5 必须 t20检出工作槽与隔离副本的差异，记录`auth_rejected=1`、`auth_restored=1`；未篡改组 mode5 不可发生认证误报。即使检出篡改，也仍要独立满足真实部署到动态影子的epsilon20、物理L1和控制L2才算恢复成功；“认证正确”不等于“恢复成功”。
- 归档最少47个诊断维，新增 `auth_rejected`、`auth_restored`、`auth_check_count`，对负面结果零过滤。每场景32行摘要、4方法×8原始JSONL，每条480点；完整SHA256、独立Python逐点再计算、实验commit链接。工作流失败不能改写为科研失败。

## 论证边界
- 比特一致性比对仅在“可信参考槽无篡改、攻击者无法同步改写签名和参考”的强信任假设下有效，实际部署需 HMAC/数字签名及独立密钥根、单调防回滚计数器、远程认证与安全存储攻击测试。本研究没有真正实现或认证这些硬件密码学条件。
- 归一化物理量与采样安全0越界不能当作G5连续时间RB-CBF QP形式可行性；经验动态参数追踪不等于完整FL神经策略 G3 全局收缩。
- 新探索完成后冻结对应源码/超参/目标并启用另一组未见新种子（例如160–199）作独立确认；不得利用旧80–119或本次120–127作为新方案确认集。
