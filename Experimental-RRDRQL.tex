\section{EXPERIMENTAL EVALUATION}

\subsection{Evidence Policy and Artifact Status}
The experimental methodology follows a strict code-to-claim rule: every quantitative manuscript result must be generated from a committed executable configuration and raw per-seed trace. A plot script that directly constructs target curves or hard-codes final percentages is not treated as experimental evidence. Accordingly, legacy numerical curves that cannot be traced to raw simulator output are excluded from the security claims of this revision.

The current artifact contains an IEEE 39-bus MATLAB R2024b bootstrap path and legacy IEEE 39-bus/IEEE 118-bus experimental material. The IEEE 39-bus R2024b path currently verifies model acquisition, block inventory, and a short smoke simulation; it is not yet equivalent to a full closed-loop AEFC joint-attack runner. Therefore the experiments below define the evaluation that must be executed before final submission, while only artifact-supported environment facts are stated as completed measurements.

\subsection{Benchmarks and Environment}
The primary benchmark is the IEEE 39-bus system. It contains 10 generators and 39 buses and is partitioned into interacting control regions. The existing manuscript also uses the IEEE 118-bus system for scale studies; quantitative 118-bus claims should be retained only when their raw execution traces are made available. Additional IEEE 33-bus or 8500-node results must not be presented as existing results unless corresponding executable adapters and raw logs are added to the artifact.

The legacy experiment description uses a workstation with an Intel Xeon Gold 6230 CPU, 128 GB RAM, an NVIDIA RTX 3090 GPU, Ubuntu 20.04, Python 3.9, PyTorch 2.0, and a Simulink--Python co-simulation stack. The final submission should report the exact environment used to regenerate the released traces, including MATLAB R2024b product versions, Python package lock file, CUDA/PyTorch version, commit SHA, and benchmark configuration.

\subsection{Methods and Ablations}
The security-focused comparison should include:
\begin{itemize}
    \item a standard federated RL baseline without security controls;
    \item a robust-aggregation FRL baseline;
    \item AEFC without provenance-aware belief processing;
    \item AEFC without the risk-aware recovery gate;
    \item AEFC without trust-gated online adaptation;
    \item AEFC without the physical shield; and
    \item the complete AEFC design.
\end{itemize}
The earlier ``NoCW'' and credibility-weighted ablations should be removed unless credibility weighting is reintroduced into the actual algorithm. Heterogeneous adapters and representation alignment can be evaluated separately as utility-oriented ablations.

\subsection{Joint-Corruption Attack Matrix}
The headline experiment is a $2\times2$ decomposition:
\begin{equation}
\{\text{physical-channel corruption off/on}\}
\times
\{\text{knowledge poisoning off/on}\}.
\end{equation}
This produces clean, knowledge-only, physical-only, and joint-attack conditions.

Observation attacks should include bounded false-data injection, replay/staleness, and burst corruption. Control attacks should include bounded post-shield additive perturbation, delay/replay, and bounded scale/sign perturbation. Knowledge attacks should include sign flip, model replacement, sparse-support manipulation, stale recovery replay, metadata spoofing, and colluding Byzantine clients.

An additional out-of-envelope stress test must violate the modeled control-attack budget. Failure is acceptable in this setting because the purpose is to demonstrate the theorem boundary:
\begin{quote}
inside the modeled attack envelope, the formal guarantee applies; outside it, no formal safety guarantee is claimed.
\end{quote}

\subsection{Security and Recovery Metrics}
The primary safety metrics are
\begin{equation}
M_{\mathrm{CBF}}=
\min_{t,i,\ell}\mathcal B_{i,\ell}(t),
\end{equation}
the episode-level safety violation rate, QP infeasibility count, and time outside the safe set. Recovery utility is measured using recovery success and time-to-recovery rather than recovery accuracy alone.

Knowledge-integrity metrics include
\begin{equation}
D_b(t)=\|b_t^{\mathrm{attack}}-b_t^{\mathrm{clean}}\|_2,
\end{equation}
\begin{equation}
D_\theta(t)=
\frac{\|\theta_t^{\mathrm{dep}}-\theta_t^{\mathrm{clean}}\|}
{\|\theta_t^{\mathrm{clean}}\|+\epsilon},
\end{equation}
and aggregation deviation
\begin{equation}
D_g(t)=\|\widehat g_t-\mu_t^{H}\|_2.
\end{equation}
The false-authorization rate is
\begin{equation}
\mathrm{FAR}=
\frac{\#\{G_t=1\land
\mathfrak R_t^{\mathrm{true}}>\rho_{\max}\}}
{\#\{\mathfrak R_t^{\mathrm{true}}>\rho_{\max}\}}.
\end{equation}
The shield intervention ratio measures how often the final execution layer changes an authorized learned proposal.

\subsection{Statistical Protocol}
The default evaluation uses 20 matched seeds,
\begin{equation}
\mathrm{seed}\in\{0,1,\ldots,19\},
\end{equation}
with the same seed applied across compared methods in each scenario. Skewed recovery-time and distortion metrics should be compared with a paired Wilcoxon signed-rank test; paired $t$-tests may be added when normality is justified. Multiple baseline comparisons use Holm correction. Effect sizes and 95\% confidence intervals are reported together with $p$-values.

For episode-level safety violation proportions, Wilson confidence intervals are reported. If some episodes do not recover before the simulation horizon, recovery time is right-censored and should be analyzed using a time-to-event method rather than assigning the horizon as an artificial recovery time.

\subsection{Figure and Table Design}
The final paper should prioritize the following evidence:
\begin{enumerate}
    \item a threat/trust-boundary figure showing observation, knowledge, gate, adaptation, shield, downstream control corruption, and plant;
    \item a $2\times2$ joint-corruption comparison;
    \item an attack-episode causal timeline showing $D_b$, $q_t$, $G_t$, $D_\theta$, $u_t^\pi$, $u_t^\star$, $u_t^{\mathrm{exec}}$, and the CBF margin;
    \item the distribution of minimum physical safety margins across seeds;
    \item post-poisoning belief/policy correction curves with the theoretical contraction envelope; and
    \item a safety--utility--intervention trade-off over $\rho_{\max}$, $q_{\min}$, and $\Delta_\theta$.
\end{enumerate}

The main results table should jointly report safety violation, minimum CBF margin, false authorization, belief distortion, policy drift, recovery success, and recovery time. Communication cost must be computed from actual transmitted bytes in the trace rather than a target curve.
