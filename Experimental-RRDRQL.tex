\section{EXPERIMENTAL EVALUATION}

\subsection{Evidence Policy and Evaluation Backends}
Every quantitative result reported in this paper is generated from a committed executable configuration and per-seed traces. Tables and statistical summaries are derived from those traces rather than from manually specified target curves. The released artifact contains two deliberately separated evaluation paths.

The first path is a reduced-order CPS integration backend used to exercise the complete PATBU--risk-gate--trust-gated-adaptation--aggregation--shield--post-shield-attack composition. It is reported only as mechanism-level evidence. The second path is the native MathWorks R2024b \texttt{IEEE39BusSystem} model. The native workflow materializes the official example, discovers candidate observation and control edges, validates the selected pairs by finite-difference causal probing, instruments the validated model, and executes the same method/scenario matrix used by the mechanism-level evaluation.

The authoritative native run uses four generator-local physical rotor-speed/\texttt{Pref} pairs at Gen10@Bus30, Gen1@Bus39, Gen2@Bus31, and Gen3@Bus32. The resulting $4\times4$ finite-difference sensitivity matrix has rank four and condition number 5.13. The native evidence is tied to commit \texttt{cc315ff522c90ce6adc09df3020472dd9ad820ea}, uses a $1/60$~s sample time, and executes $7\times4\times20=560$ episodes with one Fast Restart compile and numeric tunable selectors. The orientation-safe extraction path applies per-episode semantic guards before a trace is accepted.

\subsection{Experimental Setup}
\label{subsec:experimental-setup}
The Main Experiment keeps the native plant, causal mapping, attack timing, and controller parameters fixed across all seven methods. Each episode lasts 1.20~s at $1/60$~s, giving 73 recorded samples including $t=0$. The attack interval is steps 15--43 (29 controller samples). Seven federated clients participate, of which two are Byzantine, and the robust common support has cardinality three. The four scenarios are clean, knowledge-only, physical-only, and joint corruption, corresponding to the Cartesian product of physical corruption off/on and knowledge poisoning off/on. Each method/scenario cell uses 20 seeds, yielding 560 native episodes in the authoritative matrix.

Table~\ref{tab:experimental-settings} records the fixed parameters used by the native Main Experiment. Observation corruption acts on the four validated rotor-speed channels; the value 0.25 is expressed relative to each channel's normalization scale. The control-channel adversary is downstream of the shield and is bounded by 0.005 per channel. Knowledge corruption combines model replacement (scale 6), sign-changing malicious updates, stale evidence delayed by seven steps, and collusion of the two Byzantine clients.

Five supplemental experiments are pre-specified and do not alter the 560-run Main Experiment. E1 scales the complete joint corruption by $\gamma\in\{0,0.5,1,1.5,2\}$ for FedRL, RobustAgg, AEFC-no-PATBU, AEFC-no-Gate, and AEFC-Full; $\gamma=0$ reuses the Main clean cell and $\gamma=1$ must reproduce the Main joint cell. \subsection{Methods and Joint-Corruption Matrix}
The comparison includes a standard federated RL baseline (FedRL), a robust-aggregation baseline (RobustAgg), AEFC without PATBU, AEFC without the risk gate, AEFC without trust-gated online policy adaptation, AEFC without the physical shield, and AEFC-Full. Heterogeneous adapters and representation alignment are not treated as security ablations in the reported tables because they address subsystem compatibility rather than recovery authority.

The four Main-Experiment scenarios form a $2\times2$ corruption matrix:
\begin{equation}
\{\text{physical corruption off/on}\}
\times
\{\text{knowledge poisoning off/on}\}.
\end{equation}
Observation attacks perturb the selected physical rotor-speed channels. Control corruption is injected after the shield and before the validated native actuator edge, preserving the threat-model ordering
$u_t^\pi\rightarrow u_t^\star\rightarrow u_t^{\mathrm{exec}}$. The formal guarantee applies only inside the modeled uncertainty and attack sets; the reported experiments do not claim safety against arbitrary unbounded downstream actuation.

\subsection{Security and Recovery Metrics}
Belief integrity is measured against the clean counterfactual belief,
\begin{equation}
D_b(t)=\|b_t-b_t^{\circ}\|_2.
\end{equation}
The reported policy-drift metric is the movement of the deployed policy from its pre-update reference,
\begin{equation}
D_\theta(t)=\|\theta_t^{\mathrm{dep}}-\theta_0^{\mathrm{dep}}\|_2,
\end{equation}
which matches the quantity recorded by both executable backends. It should not be interpreted as a normalized attacked-versus-clean parameter distance unless such a clean parameter trajectory is explicitly recorded.

For the native IEEE 39-bus path, let $z_t$ denote the four normalized physical rotor-speed observations and let $\ell_{\mathrm{safe}}=1$ be the configured normalized envelope. The instantaneous native margin is
\begin{equation}
m_t^{\mathrm{native}}=\ell_{\mathrm{safe}}-\|z_t\|_\infty,
\end{equation}
and each episode reports $\min_t m_t^{\mathrm{native}}$. A negative value therefore denotes an observed envelope violation.

The false-authorization rate is computed from the logged dangerous-proposal indicator $d_t\in\{0,1\}$:
\begin{equation}
\mathrm{FAR}=
\frac{\sum_t\mathbf 1\{G_t=1\land d_t=1\}}
{\max\{\sum_t d_t,1\}}.
\end{equation}
The indicator is backend-specific but fixed by the executable configuration: the mechanism-level path uses a one-step true-state surrogate safety criterion, whereas the native path uses the normalized predicted envelope associated with the validated sensitivity model. Consequently, empirical FAR is an operational authorization metric; it is not itself an estimate of the theoretical probability parameter $\delta_g$.

Recovery is summarized by an episode-level recovery-success indicator and post-attack time-to-recovery. Safety is summarized by the episode-level violation indicator and the minimum native margin. The shield-intervention ratio records the fraction of time steps at which the execution layer changes the authorized proposal.

\subsection{Statistical Protocol}
The native Main Experiment uses the same 20 seeds, $\mathrm{seed}\in\{0,1,\ldots,19\}$, across methods within each scenario. Continuous native integrity, margin, and recovery metrics are therefore compared with paired Wilcoxon signed-rank tests; for each metric, the six AEFC-Full-versus-alternative comparisons are corrected with Holm's procedure. Exact all-zero paired differences are assigned $p=1$ before multiplicity correction.

The original reduced-order mechanism experiment also uses 20 per-method seeded runs, but its random stream was derived from both the seed and the method identifier. Its original table is therefore retained as multi-run descriptive mechanism evidence (means and confidence intervals), not as a strict common-random-number paired experiment. E3 supplies the fairness-calibrated inferential comparison: all four methods receive method-independent common random numbers, and AEFC-Full-versus-baseline continuous metrics use paired Wilcoxon tests with Holm correction across the three alternatives. E2 applies paired Wilcoxon tests to Full versus no-PATBU at each of four attack intensities and corrects those four tests with Holm's procedure. E4 uses Spearman rank correlation across the seven method means. Episode-level binary proportions use Wilson 95\% confidence intervals; continuous table entries use mean 95\% confidence intervals across the 20 runs.
